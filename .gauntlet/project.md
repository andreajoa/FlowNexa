# FlowNexa runtime

Instagram automation SaaS for creators, shops and agencies. Production public site and private app share https://flownex.online, dedicated Vercel team flownexa3/project flownexa and dedicated Cloudflare D1. Node runtime via api/index.js, durable encrypted queue, Cloudflare minute scheduler. Owner-authorized Instagram @atenzaon connected through actual OAuth, professional account token encrypted. Public website layout, user assets and brand must be preserved; signup links may be wired to app. Recurring payments must use Stripe Embedded Checkout, with authoritative signed webhooks and self-service portal.

Owner priorities: beginner-friendly click-based editor, create from scratch or ready models, consistent original brand, competitively priced recurring plans and substantial automation.
